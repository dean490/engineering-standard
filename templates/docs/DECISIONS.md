# Decisions

Decisions that are expensive to reverse, recorded so they aren't argued again (constitution I; STANDARD 8.3).

**Format.** Newest first. One entry per decision, with these fields. Never rewrite a past entry; a reversal is a new entry that names the one it replaces. Leave a field blank rather than guess (constitution XII).

## <YYYY-MM-DD>: <decision, as one sentence>

- **Decision:** <what was decided>
- **Rationale:** <why>
- **Alternatives rejected:** <each option considered and why it lost>
- **Decided by:** <Owner / Planner>
