# Deviations

Intentional differences between the spec and the code, so none is left implicit (constitution I; STANDARD 8.3). A difference that isn't intentional is a bug, not a deviation.

**Format.** One entry per deviation, newest first. Remove an entry when the spec or the code changes to remove the difference, and say which change did it.

## D<n>: <short title>

- **Spec says:** <section and requirement>
- **Code does:** <what it does instead, with file paths>
- **Why:** <reason, and the decision or brief that approved it>
- **Until:** <when or what will end it, or "permanent">
